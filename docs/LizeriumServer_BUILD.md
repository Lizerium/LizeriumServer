## `appsettings.json`

1. Create your own `LizeriumServer/appsettings.json`
2. In `appsettings.json`, configure the following paths:
   1. `KnowledgeBase` — path to the Knowledge Base
      - available here: https://github.com/Lizerium/KnowledgeBase

   2. `LauncherRoot` — path to the launcher directory

   3. `ModsRoot` — path to mods / game builds

   4. `GameServerConfigs` — directory containing `BUILDS`
      - this folder contains crafting recipe files generated by:  
        https://github.com/Lizerium/LizeriumModManager

      Inside this directory you should have:
      - `craft_builda.json`
      - `craft_builde.json`
      - `craft_buildl.json`
      - `craft_buildw.json`

   5. `BlackList` — path to the file containing blocked IP addresses

   6. `GoogleReCaptcha` — keys for Google reCAPTCHA integration

---

### Example `appsettings.json`

```json
{
	"Logging": {
		"LogLevel": {
			"Default": "Information",
			"Microsoft.AspNetCore": "Warning"
		}
	},
	"AllowedHosts": "*",
	"BlackList": "full_path_to_file_46722929.ini",
	"GoogleReCaptcha": {
		"SiteKey": "your_SiteKey",
		"SecretKey": "your_SecretKey",
		"Version": "v3"
	},
	"StoragePaths": {
		"ModsRoot": "full_path_to_PROJECTS_UPDATES",
		"LauncherRoot": "full_path_to_LAUNCHER_RELEASE",
		"KnowledgeBase": "full_path_to_KnowledgeBase",
		"GameServerConfigs": "full_path_to_GameServerConfigs"
	}
}
```

## `dev_mode.json`

1. Create your own `LizeriumServer/dev_mode.json`
2. Configure the following:
   1. `DevelopMode` — enables development mode
      - when enabled, the site is publicly accessible but restricted:
        - only trusted users (via `UpdaterWhiteList`) can interact fully
        - others see a maintenance/unavailable banner

   2. `UpdaterState` — enables update launcher functionality

   3. `UpdaterDevMode` — restricts update launchers to trusted users only

---

### Example `dev_mode.json`

```json
{
	"DevelopMode": false,
	"UpdaterState": true,
	"UpdaterDevMode": true,
	"UpdaterWhiteList": ["your_global_ip_address", "::1"]
}
```

## `downloads.json`

1. Create your own `LizeriumServer/downloads.json`
2. Configure paths and keys for downloadable content defined in:

`Views/Home/Game.cshtml`
