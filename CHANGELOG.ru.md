# Обновления

## 08.08.2026

### Главный сервер Lizerium Server

- Для CSS страниц базы знаний, документации и поддержки включен `asp-append-version`, чтобы браузеры пользователей автоматически получали новые стили после деплоя без ручного `Ctrl+F5`.
- Исправлено визуальное состояние источников видео в новостях: теперь ярко выделяется только выбранная площадка, а не все доступные кнопки YouTube/VK/Rutube одновременно.
- Исправлено переключение типа видео прямо на карточке новости: выбор YouTube/VK/Rutube теперь обновляет активную кнопку и передается в полный просмотр новости даже для карточек с постером вместо встроенного iframe.
- Карточки новостей теперь показывают первый содержательный Markdown-блок статьи с inline-разметкой, пропуская обложки, изображения, видео и заголовки, которые должны оставаться частью полного чтения.
- Пересобраны клиентские ассеты `global.min.css` и `app.min.js` для доставки исправлений стилей и поведения новостных карточек.

### Админка Api Lizerium Server

- Исправлен сломанный предпросмотр изображений новостей на боевом API-домене: локальные `/img/news/...` теперь отдаются через защищенные маршруты `/news/assets/preview` и `/news/image/{fileName}`.
- В редактор новостей добавлена защищенная галерея изображений: поиск загруженных файлов, вставка картинки в Markdown, добавление в `ImageGalleryJson`, установка обложкой и удаление физического файла.
- Для уже прикрепленных картинок галереи добавлено открепление от новости без удаления самого загруженного файла.
- Добавлен закрытый предпросмотр новости по маршруту `/news/preview/{id}`: он доступен только после проверки `AdminAccessGuard`, IP-блокировок и авторизованной `AdminSession`.
- Предпросмотр умеет открывать скрытые/неопубликованные новости, поэтому черновик можно сохранить без публикации и проверить до выкладки на основной сайт.
- Предпросмотр новости разделен на два состояния: карточка в публичном списке новостей и полный текст статьи при чтении.
- Карточка в админском предпросмотре использует ту же Markdown-логику анонса, что и публичная карточка новости.
- Исправлена верстка админского предпросмотра новости: текст больше не наследует центрирование статьи, изображения получают fallback на публичный домен `lizerium.com`, а карточки видео-новостей показывают постер YouTube/Rutube при отсутствии отдельной обложки.
- В списке новостей админки добавлена кнопка `Предпросмотр`, открывающая закрытую страницу в новой вкладке.
- В форме создания новости добавлена подсказка: предпросмотр появляется после первого сохранения записи, а для черновика нужно снять галочку публикации.
- В галерею изображений новостей добавлена серверная пагинация и поиск с задержкой ввода, чтобы большие папки загрузок больше не подвешивали браузер при открытии выбора файла.
- Исправлен вывод изображений новостей в API-предпросмотре: обложки, иконки, галерея и Markdown-картинки теперь идут через защищенный preview endpoint с более устойчивым поиском файлов на боевом сервере.
- Исправлен вывод inline Markdown-картинок в API-предпросмотре новости: `![image](...)` теперь рендерится даже внутри обычного текстового абзаца.

### База данных и тесты

- Добавлен метод `GetAdminLauncherNewsByIdAsync`, который получает новость по id без фильтра `IsPublished` только для админских сценариев.
- Добавлен регрессионный тест, подтверждающий, что скрытая новость доступна для админского предпросмотра.

### Заметки по обновлению

- Новые продуктовые таблицы создаются автоматически через `CREATE TABLE IF NOT EXISTS`; для других СУБД, кроме текущего SQLite-сценария, нужно отдельно проверить совместимость SQL.
- Стартовый seed продуктов выполняется только когда таблица категорий продуктов пустая.
- Для загрузки и предпросмотра изображений продуктов должен быть доступен путь `appSettings:portalImagesPath` или `LizeriumServer/wwwroot/img`.
- Публичная страница `/Home/Game` теперь ожидает модель `GameProductsViewModel`.
- `ReCaptcha` регистрируется через `AddReCaptcha(...)`, а не только через `Configure<ReCaptchaSettings>`.
