# Обновления

## 01.08.2026

### Главный сервер Lizerium Server

- Добавлена SEO-конфигурация `SeoDomains` для работы одного сервера сразу на `lizerium.com` и `lizup.ru` без дублирования проекта.
- Добавлена динамическая генерация canonical, OpenGraph, VK preview и JSON-LD URL в зависимости от выбранного SEO-режима домена.
- Добавлена генерация `/sitemap.xml` и `/robots.txt` с учётом текущего домена запроса: каждый домен получает ссылки на свой host, а canonical страниц при этом может указывать на основной домен.
- Добавлен пример `appsettings.example.json` с настройками `PrimaryDomain`, `Domains`, `Scheme`, `CanonicalMode`, `OpenGraphImage` и `SiteName`.
- Обновлена документация по сборке и деплою: описана настройка nginx для нескольких доменов и передача forwarded host headers.

## 31.07.2026

### Главный сервер Lizerium Server

- Добавлена новостная лента Lizerium Launcher на `/Home/Launcher` с поиском, сортировкой по новым/старым, пагинацией и RU/EN-контентом.
- Добавлена поддержка хранения `launcher_news`: автоматическое создание таблицы, добавление недостающих колонок, стартовые новости, выборки для сайта/админки, сохранение, удаление и публичный счётчик лайков.
- Добавлена модель `LauncherNewsDataResponse` с RU/EN заголовками и Markdown, ссылками YouTube/Rutube/VK, обложкой, галереей, иконкой продукта, типом новости, GitHub-ссылкой, статусом публикации, порядком сортировки и датой публикации.
- Добавлен полный просмотр новости с Markdown, галереями, обложкой/иконкой продукта, GitHub-ссылкой, лайками, локализованным Share/копированием и навигацией.
- Добавлена поддержка медиа внутри Markdown: картинки, `@video(...)`, `@video-vertical(...)` и отдельные строки со ссылками YouTube/Rutube/VK.
- Добавлен приоритет видеоплощадок по локали: RU - Rutube/VK/YouTube, EN - YouTube/VK/Rutube, ручное переключение площадок и сообщения о недоступной площадке.
- Добавлены RSS-ленты новостей: `/news/rss.xml` и `/rss/news.xml`.
- Добавлены интеграционные/регрессионные тесты для Markdown, скриптов лаунчера и тестовых новостей.
- Обновлены стили, мобильная адаптация и локализация страницы новостей лаунчера.

### Админка Api Lizerium Server

- Добавлена отдельная страница управления новостями лаунчера с поиском и карточками редактирования.
- Добавлены создание, редактирование, удаление, публикация и сортировка новостей, включая RU/EN заголовки, Markdown, тип новости, YouTube/Rutube/VK URL, GitHub-данные и дату публикации.
- Добавлены отдельные загрузки иконки продукта, обложки, галереи и картинок, вставленных в Markdown через буфер обмена; файлы проверяются как изображения и ограничены 8 MB.
- Добавлены превью иконки, обложки, галереи и Markdown-картинок, а также клиентские помощники загрузки/вставки в `news.js`.
- Добавлены `admin_access.json` и `AdminAccessGuard` для опционального доступа к админке по доверенным IP.
- Добавлена страница `AccessClosed` для закрытого доступа в админку.
- Добавлены постоянные DataProtection-ключи и расширенная админская сессия на 8 часов, чтобы долгие правки не сбрасывали авторизацию.
- Добавлено определение ботов по user-agent и расширен мониторинг кабинета: пагинация, почасовая активность, счётчики людей/ботов и визитов.
